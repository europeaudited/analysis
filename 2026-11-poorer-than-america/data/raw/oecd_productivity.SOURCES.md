OECD Productivity database, dataflow OECD.SDD.TPS:DSD_PDB@DF_PDB (v2.0), ACTIVITY=_T (total economy), years 2015, 2019, 2024, pulled 2026-11-15 via the OECD SDMX API (https://sdmx.oecd.org/public/rest/data/OECD.SDD.TPS,DSD_PDB@DF_PDB,2.0/).
Measures: GDPHRS = GDP per hour worked, USD, current prices, current PPPs (column gdp_per_hour_usd_ppp). HRSPOP = hours worked per head of population, per year (hours_per_capita). HRSAV = average hours per worker per year (hours_per_worker). EMP = employment, thousands (employment_thousands). POP = population, thousands (population_thousands). GDPPOP_LR = GDP per head, USD, constant prices, constant 2020 PPPs (gdp_per_capita_const_2020ppp).
Areas: USA, EU27_2020, EA20 (2024 only), BEL, DEU, FRA, NLD, DNK, SWE, ITA, ESP, POL, IRL (2024 only), GBR.
Current-price GDP per head = gdp_per_hour_usd_ppp x hours_per_capita (computed in run.py).
Added column hours_total_millions = OECD HRSTO (total hours worked, millions), US only, 2024 = 292,630.3 (editor check of the OECD file; 2023 value 291,066 not in this extract, which holds 2015, 2019 and 2024). Used only to test the US hours identity: HRSTO / POP = HRSPOP and HRSTO / EMP = hours per job-holder (1,775), which differs from HRSAV (1,702).
