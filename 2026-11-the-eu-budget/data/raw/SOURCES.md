# Raw data sources (pulled 2026-11-15; relative description only)
- external_figures.csv: figures from official reports via web (Council infographic on the 2025 EU budget, ECA annual report 2024 FAQ). Copied unchanged from the shared inbox. Only the EU budget and ECA rows are used here.
- eu_gov_totals.csv: Eurostat nama_10_gdp (B1GQ, CP_MEUR), gov_10a_main (TE, S13), gov_10a_exp (COFOG, PC_GDP). Copied unchanged.
- oecd_productivity_eu27.csv: EU27_2020 rows of the OECD Productivity database (OECD.SDD.TPS, DSD_PDB@DF_PDB 2.0, ACTIVITY=_T). population_thousands is used. The file has 2015, 2019 and 2024 only: no 2025 population.
- eu_budget_extra_figures.csv (checked against the cited pages on 2026-11-15): hand-entered rows (NextGenerationEU, ECA threshold, adverse opinion, ECA 2024 spending base 191.1bn / 247.0bn incl. recovery fund 55.9bn, 19 suspected fraud cases in 812 transactions with 7 sent to the EPPO, 5.2% error in complex-rules spending; ECA FAQ Q1, Q7, Q8) read in the sources named in the url column (NextGenerationEU 72 bn read on the Commission page; ECA adverse opinion and 2% threshold read in the ECA FAQ). The NextGenerationEU figure is a Commission estimate of disbursements, not an outturn.
